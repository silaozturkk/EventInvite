# EventInvite 🎉

EventInvite is a modern web application that allows users to quickly create beautiful event invitations and export them as PDF files.

Users can select different event types, fill in event details, preview the invitation in real time, and download the final invitation.

---

## ✨ Features

- Multiple event types
  - Birthday
  - Wedding
  - Party
  - Graduation

- Dynamic form fields based on the selected event
- Real-time invitation preview
- Beautiful gradient invitation designs
- Export invitations as PDF
- Responsive and modern UI

---

## 🖥️ How It Works

1. Select an event type from the navigation bar.
2. Fill in the event details in the form.
3. The invitation preview updates in real time.
4. Download the invitation as a PDF file.
